# Demo video

The current script, image pack and the brief for the video agent are in `marketing/demo/`:

- `marketing/demo/SCRIPT.md` has the scene-by-scene script with timings, voiceover and captions.
- `marketing/demo/AGENT_PROMPT.md` has the rules for the agent that assembles the video.
- `marketing/demo/build.mjs` regenerates the PNGs (`node marketing/demo/build.mjs <screenshots-dir> --app`).

If you record the claim yourself, use a second wallet so the video shows a new user getting paid.
